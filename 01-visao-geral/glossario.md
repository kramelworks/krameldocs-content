
# Glossário

| Termo | Definição |
| --- | --- |
| API | Interface que permite que sistemas ou componentes se comuniquem. |
| App Router | Sistema de roteamento do Next.js utilizado para organizar páginas e endpoints. |
| Asset | Arquivo complementar, como uma imagem ou um PDF. |
| Branch | Linha de desenvolvimento versionada em um repositório Git. |
| Build | Processo de compilação e preparação da aplicação para execução ou publicação. |
| Cache | Armazenamento temporário de dados para evitar consultas repetidas. |
| Commit | Registro de um conjunto de alterações no Git. |
| Conteúdo editorial | Artigos e recursos que compõem a documentação. |
| Deploy | Publicação de uma versão da aplicação em um ambiente de hospedagem. |
| Endpoint | Endereço de uma rota que recebe requisições, geralmente para fornecer dados ou executar uma operação. |
| GFM | GitHub Flavored Markdown, uma variante de Markdown que inclui recursos como tabelas. |
| Git | Sistema de controle de versão utilizado para acompanhar alterações em arquivos. |
| GitHub | Plataforma de hospedagem de repositórios Git e colaboração em projetos. |
| HTML | Linguagem de marcação utilizada para estruturar conteúdo na web. |
| JSON | Formato textual utilizado para representar dados estruturados. |
| Markdown | Formato de texto simples com marcação leve para títulos, listas, links e outros elementos. |
| MDX | Formato que combina Markdown com componentes JSX. Não é suportado pelo pipeline atual do krameldocs. |
| Navegação | Árvore de grupos e páginas configurada em `navigation.json`. |
| Next.js | Framework React utilizado para construir a aplicação web. |
| Node.js | Ambiente de execução JavaScript utilizado no desenvolvimento e na execução de ferramentas do projeto. |
| Repositório | Local versionado que contém arquivos e o histórico de alterações de um projeto. |
| Sanitização | Processo de restringir conteúdo potencialmente inseguro antes de sua apresentação. |
| Token | Credencial utilizada para autenticar uma requisição a um serviço. |
| TTL | *Time To Live*: tempo de validade de uma entrada em cache. |
| TypeScript | Linguagem baseada em JavaScript que adiciona verificação estática de tipos. |
| URL | Endereço utilizado para localizar um recurso na web. |
| Variável de ambiente | Valor de configuração fornecido ao processo sem precisar ser fixado no código. |
| Vercel | Plataforma de hospedagem utilizada para publicar a aplicação web. |

## Convenção de nomenclatura

Ao longo da documentação, nomes de arquivos, variáveis, rotas e propriedades de configuração são apresentados em fonte monoespaçada, por exemplo: `navigation.json`, `DOCS_GIT_BRANCH` e `GITHUB_TOKEN`.

## Atualização do glossário

Quando um novo termo técnico passar a ser utilizado de forma recorrente, avalie incluí-lo nesta lista. As definições devem ser curtas, consistentes e compatíveis com o comportamento real da plataforma.
